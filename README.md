# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 开局前复习排程

收藏页内建「开局前复习排程」面板，流程为 **规划 → 复习中 → 已锁定**：

- 选择玩家人数与可用分钟，并从支持当前人数的收藏中勾选多款游戏；**复杂度为「重」且支持该人数的游戏必须入选**（自动勾选、不可取消），不支持当前人数的重度游戏会单独列出提示。
- 复习时长按每条规则卡片 1 分钟估算，面板实时显示总时长、勾选进度和风险统计（重度款数、遗忘点、争议点、搁置 60 天以上款数、综合风险等级）。
- 总复习时长超过可用分钟时**整场拒绝**：不会生成排程，内联红字提示，原排程与收藏均不改动。
- 排程生成时对全部规则条目做快照。复习中需**逐项勾选**，全部完成后「结束并锁定」才可点击；进行中可放弃排程。
- 锁定后的历史只读：之后在收藏中新增或删除争议、遗忘点都不会回写或改动历史快照，面板会明示这一点；点击「规划下一场」可开启新排程（替换旧记录）。
- 规划草稿（人数、可用分钟、勾选）、复习进度、排程状态与收藏一起存入 `localStorage`，刷新页面后完整恢复。
