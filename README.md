# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 开局前复习排程

- 每次排程选择多款桌游、玩家人数和可用分钟；人数不符的桌游不可选，复杂度为「重」的桌游必须入选（自动勾选且不可取消）。
- 每款游戏的复习时长按复杂度基准（轻 6 / 中 10 / 重 15 分钟）加规则卡片条数估算；入选游戏复习时长之和超过可用分钟时整场拒绝，原排程与收藏不变。
- 生成排程后逐项勾选复习，全部完成后才能结束；结束时记录快照锁定进历史场次，之后新增的争议或遗忘点不会回写历史。
- 排程进度、风险统计（时间余量、重度游戏数、最久未玩、风险等级）、表单草稿和历史记录都同步到 localStorage，刷新后恢复。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
